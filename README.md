# С чего начать

Это бэкап учебного проекта по курсу «Анализ данных» (андан, НИУ ВШЭ, 2026/2027).
Папка самодостаточна: истории переписки не нужно.

## Инструкция для ассистента

1. **Прочитай `BRIEFING.md` целиком** — там весь контекст: требования курса, критерии
   оценивания с разбалловкой на 20 баллов, описание данных, цепочка переменных,
   **все посчитанные числа проекта** и банк вопросов на защиту.
2. Готовый результат — `Проект_анализ_цен_автомобилей.ipynb` (136 ячеек, выполнен без
   ошибок). Он закрывает все 12 разделов требований, шапка заполнена.
3. Правила работы с кодом: только методы из `lectures/*.pdf`. Это курсовой проект,
   его защищает студент — любой метод, которого не было в лекциях, нельзя
   использовать, даже если он лучше. Ориентир — `topic1`…`topic7`.
4. Числа в выводах блокнота должны совпадать с числами в `BRIEFING.md` (раздел 7).
   Если что-то переcчитывается — сверять до копейки.

## Чтобы запустить блокнот

```
Проект_анализ_цен_автомобилей.ipynb
Автомобили.xlsx          ← уже лежит рядом (копия из data/)
```

Первая ячейка читает файл по имени `Автомобили.xlsx` из текущей папки.
Нужные библиотеки: `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`,
`scipy`, `statsmodels`, `openpyxl`.

## Что осталось сделать руками

Перепроверить прогон у себя (Restart Kernel → Run All) и сдать. Шапка (команда 180,
Павчун Дмитрий — 8, Алимова Яна — 11) уже заполнена.

## Что сдаётся в SmartLMS

Два файла, загружает один человек от команды:
`Проект_анализ_цен_автомобилей.ipynb` и `Автомобили.xlsx`.
**Любой другой формат блокнота = 0 баллов.**
